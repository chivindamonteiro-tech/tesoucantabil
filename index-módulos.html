ℹ️ Como Funciona a Integração
  • Base de dados única: Os três módulos partilham os mesmos dados via localStorage
  • Sincronização automática: Qualquer alteração num módulo aparece nos outros
  • Navegação cruzada: Cada módulo tem botões para ir aos outros
  • Fluxo recomendado: Tesouraria (entrada) → Contabilidade (registos) → Análise Contábil (custos)
  • Sem servidor: Todos os dados são armazenados localmente (segurança e privacidade)
